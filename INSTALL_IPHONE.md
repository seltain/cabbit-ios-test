# Установка Cabbit Test на физический iPhone через Sideloadly

## Подготовка

Сначала получите **реальный** `CabbitTest-unsigned.ipa` по [BUILD_IOS.md](BUILD_IOS.md). В текущем локальном комплекте IPA ещё нет. Нужны Windows, iPhone с iOS 15.1+, USB-кабель с передачей данных, бесплатный Apple ID и интернет для подписи/первой проверки доверия.

1. Скачайте актуальный Sideloadly с [официального сайта](https://sideloadly.io/).
2. Для Windows сайт Sideloadly указывает **обычные web-версии iTunes и iCloud** и предлагает ссылки на них. Следуйте этим текущим требованиям; версии из Microsoft Store могут мешать обнаружению устройства. После установки компонентов при необходимости перезагрузите Windows.
3. Подключите iPhone по USB, разблокируйте и подтвердите **«Доверять этому компьютеру»**, введите код устройства. Убедитесь, что iTunes видит iPhone.
4. Узнайте точную версию iOS: **Настройки → Основные → Об этом устройстве**. Если это бета новой iOS, совместимость Sideloadly нужно проверять отдельно.

Apple ID и пароль вводятся только вами в Sideloadly. Не вводите их в GitHub, исходники или чат. Для бесплатной подписи FAQ Sideloadly не рекомендует рассчитывать на app-specific password: используйте обычный вход с подтверждением 2FA, если его запросит Apple. Если потребуется принять соглашение Apple Developer, войдите в [Apple Developer](https://developer.apple.com/account/) и примите бесплатное соглашение; оплачивать membership для этого теста не требуется.

## Подпись и установка

1. Откройте Sideloadly и выберите подключённый физический iPhone в списке устройств.
2. Перетащите **`CabbitTest-unsigned.ipa`** в окно программы. Внешний ZIP с GitHub сначала распакуйте.
3. Введите свой Apple ID. Используйте обычный режим подписи/установки через Apple ID; не выбирайте режимы Normal Install или Ad-hoc sign для этого неподписанного файла.
4. Для первого теста оставьте остальные настройки стандартными. Если доступны дополнительные действия, не включайте инъекции tweaks/frameworks и не добавляйте entitlements.
5. Нажмите **Start**. Самостоятельно введите пароль и код 2FA в запросах Sideloadly/Apple.
6. Дождитесь сообщения об успешном завершении. Программа должна подписать главное приложение и библиотеки, добавить provisioning profile и установить приложение на выбранный iPhone.

Исходный Bundle ID — `com.cabbit.iostest`. Sideloadly может адаптировать его для бесплатного аккаунта. Для повторной установки используйте тот же Apple ID и те же настройки Bundle ID, чтобы обновлять это приложение. Не задавайте Bundle ID основного Cabbit.

## Разрешить запуск на iPhone

1. Откройте **Настройки → Основные → VPN и управление устройством**. Найдите профиль с вашим Apple ID, выберите **Доверять** и подтвердите. Названия пунктов могут немного отличаться между версиями iOS; если Apple просит онлайн-проверку/перезапуск, завершите её.
2. На **iOS 16+** включите **Настройки → Конфиденциальность и безопасность → Режим разработчика / Developer Mode**. Подтвердите перезагрузку и затем включение режима после разблокировки. [Apple описывает этот процесс](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).
3. Если Developer Mode ещё не отображается, сначала выполните подпись/установку, затем снова проверьте настройки. Если Sideloadly сообщил `Developer Mode Required`, включите режим и повторите установку при необходимости.
4. Найдите **Cabbit Test** на домашнем экране или в библиотеке приложений и запустите.

## Проверка успеха

Проверьте и запишите результат в [TEST_STATUS.md](TEST_STATUS.md):

- Приложение установлено на физический iPhone и запускается.
- Видны белый экран, «Cabbit Test» и русский подзаголовок.
- На старте счётчик равен `0`; десять нажатий дают `10`.
- Закройте приложение полностью. Включите авиарежим, дополнительно отключите Wi-Fi, отсоедините USB и запустите снова. Экран должен открыться, а кнопка работать без Windows, Metro или сервера.
- После полного перезапуска счётчик снова `0`: это ожидаемо, постоянное хранение не добавлялось.

Для первичной подписи и проверки доверия нужен интернет; офлайн-работа относится к самому установленному приложению в пределах срока действующей подписи.

## Ограничения бесплатного Apple ID

По [Apple Developer](https://developer.apple.com/help/account/basics/about-your-developer-account) и [Sideloadly FAQ](https://sideloadly.io/faq.html):

- **7 дней** действия provisioning/подписи. После истечения приложение перестаёт запускаться; подпишите и установите тот же IPA заново. Пересобирать неизменённое приложение каждую неделю не нужно.
- **До 3 таких приложений на одном устройстве**, до 3 зарегистрированных тестовых устройств для Personal Team.
- **До 10 App IDs за 7 дней**. Частая смена Bundle ID расходует этот лимит; удаление приложения не обязательно освобождает App ID сразу.
- Бесплатный аккаунт предназначен для личного тестирования. Для обычной публикации в App Store/TestFlight и расширенных capabilities потребуется отдельный процесс и членство Apple Developer Program. Не все capabilities доступны Personal Team; в этом тесте специальные возможности не используются.
- Sideloadly поддерживает автопродление, когда его daemon работает и iPhone доступен по USB или настроенному Wi-Fi. Автопродление не отменяет лимит 7 дней; сначала проверьте обычную USB-установку.

## Частые ошибки

| Симптом | Действие |
| --- | --- |
| `No devices detected` | Разблокируйте iPhone, подтвердите доверие, проверьте data-кабель, iTunes/iCloud по требованиям Sideloadly. |
| `Untrusted Developer` / приложение не проверено | Доверьтесь профилю в VPN и управлении устройством; обеспечьте интернет для проверки Apple. |
| `Developer Mode Required` | Включите Developer Mode на iOS 16+, перезагрузитесь и подтвердите. |
| Максимум приложений | Освободите слот среди других sideloaded-приложений. |
| Максимум App IDs | Дождитесь обновления лимита; не создавайте новый ID при каждом тесте. |
| Ошибка входа/anisette | Проверьте текущий [FAQ Sideloadly](https://sideloadly.io/faq.html), компоненты Apple, время/дату и доступ к сети. |
| Неверная архитектура/IPA | Используйте `CabbitTest-unsigned.ipa` из device-workflow; симуляторный `.app` не подходит. |
| Через неделю перестало открываться | Повторите подпись и установку того же IPA тем же Apple ID. |
| Падает сразу при действующей подписи | Сохраните crash-log iOS и логи Sideloadly; отметьте номер workflow, модель и iOS. Это ещё не успешная проверка цепочки. |

Инструкции и источники проверены 12 октября 2026 года. UI Sideloadly и правила Apple могут меняться.
