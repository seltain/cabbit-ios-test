# Cabbit iOS Test

Отдельный минимальный нативный проект для проверки цепочки **Windows → GitHub macOS runner → неподписанный device IPA → Sideloadly → физический iPhone**. Существующий Cabbit не используется и не изменяется.

Один экран: белый фон, «Cabbit Test», «Моё первое приложение на iPhone», зелёная кнопка «Нажми на меня» и счётчик. Приложение работает офлайн; счётчик хранится в памяти и после полного перезапуска начинается с нуля.

Стек: Expo SDK 54.0.37, React Native 0.81.5, React 19.1.0, TypeScript 5.9.3. Единственная дополнительная runtime-библиотека — `react-native-safe-area-context`, чтобы экран учитывал вырез и нижнюю область iPhone. Серверов, регистрации, базы данных и OTA-обновлений нет.

## Начать

1. Создайте новый пустой GitHub-репозиторий `cabbit-ios-test`.
2. Загрузите в его корень файлы **этой папки**, включая `.github`, `.gitattributes` и `package-lock.json`. Не загружайте весь родительский каталог.
3. Выполните шаги [BUILD_IOS.md](BUILD_IOS.md), запустите workflow и скачайте IPA.
4. Установите через [INSTALL_IPHONE.md](INSTALL_IPHONE.md).
5. Заполните [TEST_STATUS.md](TEST_STATUS.md) после проверки на iPhone.

## Статус

**IPA пока не собран.** Подготовлены исходники, Expo/iOS-конфигурация, GitHub Actions workflow и проверки IPA. На Windows проверены TypeScript, совместимость Expo-зависимостей и production-экспорт JavaScript/Hermes для iOS. Это не нативная компиляция. GitHub Actions и установка на физический iPhone ещё не выполнялись.

Сборка не требует Expo Account, EAS или Apple ID. Подпись выполняется отдельно на Windows в Sideloadly. Бесплатная подпись действует 7 дней; максимум — 3 таких приложения на устройстве. Подробности и источники находятся в инструкции установки.
